This repository contains my code, models, and predictions for Assignment 1.

## What is in this repo
- `train_var1.py`: Python script to train the model for Phase 1 (turbine efficiency) and generate predictions.
- `train_var2.py`: Python script to train the model for Phase 2 (reservoir thermal mapping) and generate predictions.
- `generate_plots.py`: Script to generate all the plots for the report.
- `figures/`: Contains the plots generated by `generate_plots.py`.
- `BT2024032/`: Folder containing the datasets and the output prediction CSV files (`BT2024032_pred_var1.csv` and `BT2024032_pred_var2.csv`).

## How to run
Make sure numpy, pandas, scikit-learn, and matplotlib are installed.

To train the models and get the test predictions:
```bash
python3 train_var1.py
python3 train_var2.py
```

To regenerate the plots:
```bash
python3 generate_plots.py
```

## Results
- **Phase 1 (var1):** I selected a Degree 5 polynomial with Lasso regularization ($\alpha \approx 0.01$). It gives a 5-fold cross-validation MSE of 0.316 and an R2 score of 0.967.
- **Phase 2 (var2):** I selected a Degree 12 polynomial with Ridge regularization ($\alpha \approx 1.76$). It gives a 5-fold cross-validation MSE of 0.258 and an R2 score of 0.995.
